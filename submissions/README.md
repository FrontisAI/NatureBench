# NatureBench submission results

This directory contains the reviewed configuration and per-task results for
each accepted submission. Submit one track per PR to `main`. Use
`submissions/<track>/<submission-id>/submission.yaml` and
`submissions/<track>/<submission-id>/results.csv`.

See the [submission guide](../submit-results/README.md) for the checklist and how
to share original results. The leaderboard is updated with accepted results.
